# Repository instructions

- Rust only for executable code.
- Keep the evidence lanes distinct: natural model-selected durable action, the Grok
  Seal hard route, the Jason & Sol Seal natural rooms, and the post-seal durability
  stress test.
- Use the paper's operational definitions: usable self-location regulates a system-
  selected consequential action, and durable state regulates later behavior.
- Do not promote that claim into phenomenal or human consciousness, official ARC-AGI
  performance, general agency, unrestricted autonomy, or unrelated-family transfer.
- Treat seal names as mnemonic and non-exclusive. Jason is the creator and author;
  named AI collaborators receive precise contribution credit, not ownership or rank.
- Human-readable prompts and model replies are the public map surface; logs are supporting trail data.
- Print the correct answer beside every reported result, including failures.
- Preserve the vanilla short-case pass alongside its three failures.
- Use coordinate for a hypothesis plus its outcome, milestone for a boost that refueled progress, and flag for a reached destination left visible to later explorers.
- A flag is non-exclusive. It guides later work; it does not block or own the destination.
- Do not alter archived model replies or scorer outputs. A new run gets a new dated coordinate and climb card.
- Run `./run docs-check`, `./run verify --check`, `cargo fmt --check`,
  `cargo test --locked`, `cargo run --locked`, and `sha256sum -c SHA256SUMS` before
  release.
