## A Primer on Niodoo’s Runtime Telemetry

Throughout these raw logs you will see Niodoo emitting internal routing and cognitive steering tags. These tags are part of Niodoo’s implemented runtime control loop. When emitted and accepted, they trigger defined steering, routing, memory, or stopping operations. They should not be interpreted as proof of subjective experience or as transparent readouts of hidden state.

Quick guide to the cognitive controls you will encounter:

- **[Explore]** — widen the residual search space
- **[Focus]** — hold a good path and evaluate optimal trajectories
- **[Spike]** — hard break-out when the system is stuck in a loop
- **[Reset]** — clear temporary state
- **[Remember]** — save a simple fact to both disk and working memory
- **[Lock]** — commit an answer and enforce a clean stop
